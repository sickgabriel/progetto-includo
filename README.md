# 🤝 Progetto IncluDO

Questo progetto è un sistema gestionale sviluppato in **TypeScript** per facilitare l'integrazione dei migranti attraverso la formazione e il matching lavorativo.

## 🛠️ Architettura Tecnica
Il software segue i principi della programmazione orientata agli oggetti (OOP):
- **Interfacce**: Definiscono i contratti per Partecipanti, Corsi e Aziende.
- **Classi**: Gestiscono la logica di iscrizione e le offerte di lavoro.
- **Piattaforma**: Un controller centrale per la gestione del database e dei filtri.

## 🚀 Funzionalità Principali
- Registrazione partecipanti e corsi.
- Sistema di iscrizione con controllo dei duplicati.
- Filtraggio avanzato dei candidati per ambito di interesse.
- Gestione delle offerte lavorative delle aziende partner.

## 💻 Come eseguire il progetto localmente
1. Clona il repository.
2. Esegui `npm install` per installare le dipendenze.
3. Esegui `npm start` per visualizzare i test nella console.
